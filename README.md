# 🏥 Emergency Room Dashboard Template (Power BI)

Transform your hospital emergency room data into actionable insights with this fully customizable **Power BI ER Dashboard Template**. Designed for **healthcare professionals, data analysts, and BI developers**, this dashboard helps monitor and visualize key ER performance metrics in real-time.

## 📊 Dashboard Features

- 📅 **Time Filters** – Analyze patient data by day, week, or month
- 🧍‍♂️ **Patient Inflow** – Track hourly/daily trends in ER visits
- 🏷 **Triage Levels** – View patient distribution by severity
- ⏱ **Wait & Treatment Times** – Analyze average wait and length of stay
- 🛏 **Bed Occupancy** – Monitor ER bed utilization and turnaround
- 📈 **Trends & Patterns** – Identify peak hours and seasonal spikes
- 🗂 **Customizable Slicers** – Filter by age group, gender, diagnosis, and more

## 🛠 Technologies Used

- **Power BI**
- **DAX**
- **Power Query**
- **SQL / Excel (for data source)**
